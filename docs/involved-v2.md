# Involved Talent V2

## Week 1 ($2000) User Management and Survey Reports
> *An admin can import an entire client and their users from a CSV or Excel file and export a sample survey report for a user with mock data.*
- User signup and registration flow.
- Clients, Groups, and relationships.
- Bulk uploads for importing clients, groups, and users.
- User management and permissions.
- User profile completion and email verification.
- Survey report mockup and design with PDF generation and bulk email.

## Week 2 ($2000) Assignments and Reporting
> *An admin can assign a static survey to a group of users and export a report for the group. A user can complete the survey and view their report. Reports can be exported as PDF and emailed to the users.*
- Define a static 360 assessment with questions and dimensions based off of the legacy 360 assessment. This will be hard-coded and used as mock data but it will be based on viable data from the master 360 assessment.
- Individual and bulk assignment of users to the static assessment. 
- Email notifications for assignment invitations and reminders.
- User can complete the survey and view their report.
- The survey report be updated to show real data from the completed assignments.

## Week 3 ($2000) Assessment Editing and Management
> *An admin can create custom assessments and manage them.*
- Duplicate the master 360 assessment and create a new assessment.
- Create a new assessment with a new name and description and add questions and dimensions to the new assessment.
- Create custom dimensions with heirarchical relationships and subdimensions.
- A rich text editor for the question content and performance descriptors.
- Preview mode for the assessment editor to see the assessment as it will be displayed to the user.
